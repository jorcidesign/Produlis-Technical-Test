# Backend — Order Management System

Ver el [README de la raíz del monorepo](../README.md) para setup, arquitectura, decisiones técnicas y cómo correr los tests.

Comandos rápidos:

```bash
npm install
npx prisma migrate deploy
npm run start:dev   # http://localhost:3001, Swagger en /api/docs
npm test            # unit
npm run test:e2e    # e2e (requiere el servidor corriendo)
```
