# Frontend — Order Management System

Ver el [README de la raíz del monorepo](../README.md) para setup, arquitectura, decisiones técnicas y cómo correr los tests.

Comandos rápidos:

```bash
npm install
npm run dev          # http://localhost:3000 (requiere el backend corriendo)
npm run build        # build de producción
npx playwright test  # e2e (requiere frontend + backend corriendo)
```
